# INDKAN Electronics Import & Export – Mobile App

React Native (Expo) prototype for Android and iOS.

## Features
- Electronics catalog with categories, search, specs and descriptions
- Bulk order request and international trade enquiry forms
- Business contact (email, call, WhatsApp, social links)

## Tech Stack
React Native, Expo SDK 58, React Navigation, Formspree

## Run Locally
npm install
npx expo start
Scan the QR code with Expo Go (Android / iOS).
